How to add Missive data each Saturday — completing the inbound picture

Missive holds your Instagram DMs and Facebook messages. Each Saturday, take a screenshot of Missive Analytics → Types tab, last 7 days, and include it with the weekly data drop alongside the FB CSV, IG CSV, YouTube zip, and Earnings CSV.
1
Open Missive → Analytics → Types tab → set date range to last 7 days.
2
Screenshot the table showing Email / Instagram / Messenger rows with new conversations and messages received.
3
Drop all five files into the weekly message. Dashboard rebuilds in one session each week.
Once you activate Missive's Claude integration (Settings → Integrations → Anthropic → add API key), create an AI Rule that tags every inbound conversation: Retreat / Villa / Olive Oil / B2B. Weekly count becomes instant — just filter by tag. Takes about 15 minutes to configure once your API key is connected.
